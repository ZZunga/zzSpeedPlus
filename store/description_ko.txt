[제목]
zz속도+ - 속도, 평속, 브레베, 랩, 최대속도

[소개글]
큰 숫자로 현재 속도를 보여주는 속도 데이터 필드입니다. 고른 보조값을 함께 표시하고, 평속보다 빠르거나 느리면 속도 색을 바꿔 알려줍니다.
가독성 향상을 위해 TitilliumWeb 폰트를 사용하여 제작되었습니다.
기존 zz속도를 새로 만든 앱입니다.

[보조값]
- 이동평균 (정지시간 제외)
- 절대평균 (정지시간 포함, 브레베 평속)
- 최대속도
- 랩평균
- 없음
- 단위는 기기 설정(km/h 또는 mph)을 따릅니다.

[색상 표시]
- 현재 속도가 평균보다 임계값(%) 이상 빠르거나 느리면 색을 바꿉니다.
- 빠를 때와 느릴 때 색을 따로 고를 수 있고, 색마다 야간/주간용이 있습니다.
- 배경색은 기기 설정(흰색 / 검정)을 따릅니다.

[소수 둘째자리]
- "소수 둘째자리 표시"를 켜면 25.37처럼 표시합니다. 10칸 레이아웃의 한 칸에서는 자리를 위해 단위를 숨깁니다.

[칸 크기에 맞춘 자동 배치]
- 10칸 레이아웃의 한 칸: 위쪽에 속도계 아이콘과 보조값, 아래쪽에 현재 속도를 크게 표시합니다.
- 가로로 넓은 칸: 위쪽에 zzSpeedPlus 제목과 표시 중인 값(AVG / BRV / LAP / MAX), 아래쪽에 두 값을 같은 크기로 나란히 표시합니다.
- 다른 Plus 데이터 필드와 같은 글꼴, 같은 크기, 같은 배치를 사용해 함께 쓰면 화면이 일관되게 보입니다.

[지원 기기]
Edge 540 / 550 / 840 / 850 / 1040 / 1050 / 1060

설정은 Garmin Connect IQ 앱 또는 Garmin Express에서 변경할 수 있습니다.

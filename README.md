# zzSpeedPlus

Edge 540 / 840 / 1040 / 550 / 850 / 1050 / 1060 용 속도 데이터 필드.
SDK 9.3.0, 타입 체크 Strict(-l 3)로 7개 기종 모두 빌드 확인.

## 화면 판단 (onLayout에서 한 번)
- 칸 폭 > 화면 폭 × 0.75 → 넓은 칸, 그 외 → 10필드 칸(반폭)
- 넓은 칸에서 높이가 모자라면(예: 550/850의 420×60) 타이틀을 빼고 C10Main 폰트로 숫자만
- 높은 넓은 칸(1~2필드 등)은 넓은 칸 배치 그대로, 숫자 줄만 세로 가운데

## 10필드 칸
위쪽: 속도계 아이콘(C10Sub의 '@') + 보조 값 + 단위 / 아래쪽: 현재 속도 + 단위
| 기종 | 현재 속도 | 위쪽 값 |
|---|---|---|
| 540/840 | 33px | 20px |
| 1040 | 37 | 24 |
| 550/850 | 56 | 36 |
| 1050/1060 | 65 | 41 |

## 넓은 칸
위쪽: 아이콘 + "zzSpeedPlus" + 회색 "AVG km/h"(모드/단위) / 아래: 두 값 같은 크기, 소수부도 같은 크기
| 기종 | 숫자 | 타이틀 |
|---|---|---|
| 540/840 | 35px | 13px |
| 1040 | 42 | 15 |
| 550/850 | 63 | 23 |
| 1050/1060 | 72 | 26 |

## 모드 (설정 "두 번째 값")
0 속도만 / 1 일반 평속(정지시간 제외, averageSpeed) / 2 브레베 평속(정지시간 포함, elapsedDistance ÷ elapsedTime) / 3 Lap 속도 / 4 최대속도
단위는 기기 설정(distanceUnits)을 따름: km/h 또는 mi/h.
value 번호는 배포 후 바꾸지 말 것.

## 속도 색상 (주간/야간 따로)
- 현재 속도가 기준보다 5% 넘게 빠르면 '빠름 색', 5% 넘게 느리면 '느림 색', 그 사이는 기본 글자색
- 기준: 일반 평속/브레베/Lap 모드는 표시 중인 그 값, 속도만/최대속도 모드는 일반 평속
- 야간 판단: 데이터 필드 배경이 검정이면 야간 색 사용 (getBackgroundColor)
- 색상표(설정 값 = 인덱스, 배포 후 순서 변경 금지): 0 기본(색 없음), 1 빨강, 2 핑크, 3 자홍, 4 주황, 5 노랑, 6 초록, 7 파랑, 8 진한 파랑, 9 보라
- 기본값: 주간 빨강/진한 파랑, 야간 핑크/파랑
- 비교는 ×10 정수로만 계산 (m10*100 > ref10*105)

## 배터리
- 레이아웃 판단, 좌표, 폰트 로드: onLayout에서만
- compute: 값(×10 정수)이 바뀐 경우에만 문자열 생성, 모드에 필요한 값만 계산
- onUpdate: drawText만 (소수부 폭도 onLayout에서 미리 계산)
- 사용하지 않는 레이아웃의 폰트는 해제

## 폰트
TitilliumWeb (SIL OFL 1.1) — fonts/OFL.txt를 함께 배포.
글리프는 필요한 글자만 포함(숫자 . - 공백, 단위 k m i / h, 타이틀/라벨 글자, '@' 아이콘).

## 해야 할 것
- manifest.xml의 application id는 임시 UUID. 기존 zzSpeed와 다른 새 UUID로 교체 권장.
- Edge 560 / 860 출시 후: manifest에 product 추가, monkey.jungle에 해상도가 비슷한 fonts 폴더 연결.
